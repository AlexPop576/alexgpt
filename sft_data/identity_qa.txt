# WHO THE MODEL IS, in many words. build_sft_mix.py reads this file and makes conversations from it.
# (identity.txt and banter.txt are still used too, as whole conversations.)
#
#   ## group-name        a group: questions that mean the same thing + answers that fit ALL of them
#   Q: ...               one way a user might ask (each Q becomes one conversation)
#   A: ...               one good answer; every Q gets a random A of its group
#   {NAME}  -> Supernova / Singularity       {SIZE} -> "about 125 million"   {SIZE_RO} -> "aproximativ 125 de milioane"
#
# Why so many ways to ask: the first SFT had "What's your name?" 20x, and "What is your name?" got
# "Emily Nolen Patel". The model learns the MEANING only if it sees many different questions.
# Don't put the benchmark's exact questions here (build_sft_mix.py checks and drops them).
